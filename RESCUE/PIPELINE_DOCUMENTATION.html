1. PROJECT OVERVIEW COMPLETE

Problem: No published ML/DL predictor exists for HIV-2 protease inhibitor resistance. Clinical interpretation relies on rule-based tools (HIV-2EU) trained on minimal phenotypic data. HIV-2 infects 1–2M people globally; protease inhibitors are cornerstone therapy.

Our Approach: Cross-species transfer learning — pre-train on large HIV-1 protease dataset (5,683 genuine phenotypic assays), zero-shot transfer to HIV-2, then structural correction using ONION-Net features from docked complexes. First leakage-free, synthetic-data-free pipeline with fully honest metrics.

Key Innovations:

  • Synthetic data detection & quarantine (1,500 banded-noise rows removed from 7,183-row corpus)
  • Leakage-free grouped CV at 95% sequence identity (882 clusters, 714 singletons)
  • ONION-Net structural correction from 171 docked complexes (19 reps × 9 drugs)
  • Honest cross-species transfer ratio: 0.70 (RF) / 0.76 (XGB)
  • Clinical validation on 5,232-row cohort (654 sequence entries × 8 drugs): ROC-AUC 0.969
  • Full disclosure supersession of live Bioinformatics submission (COPE-compliant)
  • GOD MODE: ESM-2 650M protein language model features + drug-specific models (ridge or ensemble) + conformal prediction + mutational scanner

2.2 Synthetic Data Quarantine (Critical Integrity Fix)

Discovery: advanced_feature_extraction/transfer_learning/expand_training_database.py lines 91, 100–103 generated 1,500 synthetic rows with banded uniform noise:

score ≥ 30 → Uniform(-6.5, -4.5)
score < 30 → Uniform(-12.0, -9.5)

These were merged via fallback as Data_Source='Existing_HIV1', indistinguishable from real data. Every legacy metric used the poisoned 7,183-row corpus.

Fix: Quarantine split created (commits b16b8cf, 01320d6). All honest retraining uses 5,683 genuine rows only. Stanford_Score is NULL in all genuine rows — the R=0.722 "baseline" was a self-fulfilling artifact of the synthetic generator (n=1500 = synthetic count).

6. END-TO-END PIPELINE FLOW DEPLOYED

Contract: Sequence input → HIV-1/HIV-2 classifier → if HIV-2: sequential + structural + language model features → model → drug suitability + probability per drug.

Full GOD MODE flow:

Sequence → Classifier → ESM-2 650M (1280-D) + Biochem (2079-D) = 3359-D
→ Multi-task XGB (8 drug heads) → Conformal wrapper → Mutational scanner
1. Input: Protease sequence (99 AA, FASTA or raw string)
2. HIV-1/HIV-2 Classifier: Sequence identity to HXB2 (HIV-1) vs ROD (HIV-2). Threshold: HIV-2 if identity to ROD > identity to HXB2. Uses classify_pdb_hiv_type.py / check_hiv2_wt_consistency.py.
3. If HIV-1: Return classifier result only. No drug prediction per contract.
4. If HIV-2 — Feature Extraction:
  • 2,079-D biochemical (Z3+VHSE8+Kidera10 per residue × 99)
  • 782-D pocket (5D Z-scales × 16 residues)
5. Base Prediction (HIV-1 XGB): Pre-trained XGB on 5,683 genuine HIV-1 → base_dG per drug (8 drugs)
6. Homology Mapping: Input sequence → nearest of 19 docked representatives (≥95% sequence identity). Mapping table: sequence_to_pdb.csv + hiv2_with_drug_hash_key.csv.
7. ONION-Net Retrieval: Fetch pre-computed 10,478-D ONION-Net features for (representative, drug) from docked_onionnet_features.npz.
8. Residual Correction: Residual XGB (trained on 136 ChEMBL rows) → corrected_dG = base_dG + residual
9. IC50 Conversion: IC50_nM = exp(corrected_dG / (R×T)) with R=1.987 cal/mol·K, T=298K
10. Suitability & Probability:
  • Suitable: IC50 < 100 nM (ΔG < −9.54 kcal/mol)
  • Probability: Calibrated from IC50 distribution per drug
11. OUTPUT (JSON): 
{
  "drug": {
    "suitable": true/false,
    "probability": 0.0–1.0,
    "pred_IC50_nM": 42.3,
    "corrected_dG": -10.2,
    "base_dG": -9.8,
    "nearest_hash": "5d514c04653b",
    "identity": 1.0
  }
  // ... for all 8 drugs
}
12. GOD MODE — ESM-2 Feature Extraction: Sequence → ESM-2 650M (esm2_t33_650M_UR50D) → layer 33 hidden states → mean pooling → 1,280-D per-sequence embedding
13. GOD MODE — Multi-Task XGB: Combined 3,359-D features (ESM-2 1,280-D + biochemical 2,079-D) → per-drug XGB heads (400 trees, max_depth=12) → 8 simultaneous drug predictions with GroupKFold(5) CV at 95% identity
14. GOD MODE — Conformal Prediction: Split conformal (inductive) wrapper → per-drug prediction intervals with 90% target coverage → 98.2% achieved coverage on clinical data
15. GOD MODE — Mutational Scanner: 99 positions × 19 alternative AAs × 8 drugs = 15,048 in silico mutagenesis predictions → resistance hotspot mapping
